# dragtionary

웹페이지에서 텍스트를 드래그하면 선택 영역 옆에 뜻과 번역을 표시하는 Chrome 확장 프로그램입니다.

- 영어 단어 하나: 발음 기호, 품사, 영영 정의, 한국어 번역
- 그 밖의 단어 및 문장: 자동 언어 감지 후 선택한 언어로 번역
- 긴 문장: 무료 API 제한에 맞게 자동 분할 번역 (최대 2,000자)
- 다크 모드, 결과 복사, 영어 발음 재생 지원
- 서버, 회원가입, API 키 불필요

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 폴더(`dragtionary`)를 선택합니다.
5. 일반 웹페이지를 새로고침한 후 텍스트를 드래그합니다.

Chrome 내부 페이지(`chrome://...`)와 Chrome 웹 스토어 페이지에서는 보안 정책상 확장 프로그램이 동작하지 않습니다.

## 사용 API

- [Free Dictionary API](https://dictionaryapi.dev/): 영어 단어 정의, 품사, 발음. API 키 없이 무료입니다.
- [MyMemory Translation API](https://mymemory.translated.net/doc/spec.php): 문장 및 단어 번역. API 키 없이 무료로 사용할 수 있지만 일일 무료 사용량 제한이 있습니다.

선택 텍스트는 결과 조회를 위해 위 API로 전송됩니다. 별도 서버나 분석 도구에는 저장하지 않습니다. 프로덕션/상업 배포 전에는 각 API의 최신 이용 약관과 한도를 다시 확인하세요.

## 파일 구조

```text
manifest.json    Chrome Manifest V3 설정
background.js    언어 감지, 사전/번역 API 요청, 캐시
content.js       텍스트 선택 감지와 결과 카드 UI
content.css      페이지와 확장 UI의 스타일 격리
popup.html       확장 프로그램 설정 화면
popup.css
popup.js
```

## 알려진 제한

- 영영 사전 상세 정보는 영어 단어에만 제공됩니다. 다른 언어의 단어는 번역된 뜻을 표시합니다.
- 무료 공개 API이므로 사용량 제한, 일시적 장애, 번역 품질 편차가 있을 수 있습니다.
- PDF 뷰어, 브라우저 설정 화면, 일부 강하게 격리된 프레임에서는 선택 이벤트에 접근할 수 없습니다.
